## v0.1.2

### ✨ What's New

- Added **Device Recovery**

  - Restore previously used devices after reinstalling Synclan or moving to a new device.
  - Recover your existing device identity through the new recovery flow without creating a new device.

- Added **Notifications & Unread Badge Count**

  - Added desktop notifications for new messages and important events.
  - Added unread message badge counts to make it easier to keep track of pending messages.

### 🛠 Improvements & Fixes

- Improved **certificate export**

  - Cancelling the certificate export dialog no longer incorrectly shows a success notification.

- Fixed **logging settings persistence**

  - Changes to log file size and log file count settings are now properly saved.

Thanks for supporting Synclan ❤️
